# FPGA

Sammlung meiner FPGA- und VHDL-Lernprojekte. Die Beispiele befinden sich in Entwicklung.

## VHDL-Übungen

- `vhdl-training/register.vhd`: 32-Bit-Register mit Reset.
- `vhdl-training/clocldvd.vhd`: Taktteiler für BCLK und LRCLK.
- `vhdl-training/i2s.vhd`: I²S-Sender für Audiodaten.

Generierte Build- und Simulationsdateien werden über `.gitignore` ausgeschlossen.
